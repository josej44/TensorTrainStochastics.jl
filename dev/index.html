TensorTrainStochastics.AbstractSpinModel — Type
AbstractSpinModel

Supertype of the Ising-type spin models. Every subtype carries its couplings, its local fields and an inverse temperature β, and implements nsites, local_fields and with_beta.

source
TensorTrainStochastics.ChainModel — Type
ChainModel(J, h, β)

Open one-dimensional Ising chain with energy

E(σ) = -Σᵢ J[i] σᵢ σᵢ₊₁ - Σᵢ h[i] σᵢ ,   σᵢ ∈ {-1, +1}.

Arguments

  • J::AbstractVector{<:Real}: nearest-neighbour couplings, J[i] couples sites i and i+1 (length N-1).
  • h::AbstractVector{<:Real}: local fields (length N).
  • β::Real: inverse temperature. Any real number except NaN is accepted; negative values are needed internally (e.g. the replica swap ratio uses β₂ - β₁).

The vectors are copied, so later changes to the inputs do not affect the model. Throws an ArgumentError if N < 2, length(J) != N - 1 or β is NaN.

Example

m = ChainModel(ones(4), zeros(5), 1.0)   # homogeneous chain, N = 5
nsites(m)                                # 5
source
TensorTrainStochastics.GraphModel — Type
GraphModel(A, β)
GraphModel(m::ChainModel)

Ising model on an arbitrary graph, encoded in a symmetric matrix A: A[i,j] = J_ij for i ≠ j (0 means no edge) and A[i,i] = h_i. The energy is

E(σ) = -Σ_{i<j} A[i,j] σᵢ σⱼ - Σᵢ A[i,i] σᵢ .

Arguments

  • A::AbstractMatrix{<:Real}: square, symmetric, at least 2×2.
  • β::Real: inverse temperature (any real except NaN).

The matrix is copied. Throws an ArgumentError if A is not square, smaller than 2×2, not symmetric, or if β is NaN.

GraphModel(m::ChainModel) builds the equivalent tridiagonal model (same β).

Example

g = GraphModel([0.1 1.0; 1.0 -0.2], 0.5)   # two coupled spins
GraphModel(ChainModel([1.0, 2.0], zeros(3), 1.0)).A
source

TensorTrainStochastics.EnergySwap — Method
EnergySwap(swap::TensorTrain)

Swap step with a configuration-dependent acceptance a(x, y) (a tensor train on the joint state, e.g. tt_swap for Metropolis acceptance ≈ min(1, r)):

B'(x, y) = B(x, y) (1 - a(x, y)) + B(y, x) a(y, x) .

This conserves total probability and, for an acceptance satisfying detailed balance with respect to π₁ ⊗ π₂, leaves π₁ ⊗ π₂ invariant. Returns a function B -> B'.

Example

a = tt_swap(m1, m2, 3, 10)
Bt = distribution_b_tt(A12, P0, 100, 10, EnergySwap(a))

TensorTrainStochastics.boltzmann_swap_tt — Method
boltzmann_swap_tt(m1::ChainModel, m2::ChainModel) -> TensorTrain

Replica swap ratio on the joint state (x, y) (replica 1 in x at m1.β, replica 2 in y at m2.β):

r(x, y) = π(y, x) / π(x, y) = exp((β₁ - β₂)(E(x) - E(y))) ,

with the combined physical index x + 2(y - 1) of replica_product. The Metropolis swap acceptance is min(1, r). m1 and m2 must have the same couplings (only β may differ), otherwise an ArgumentError is thrown.

Example

TensorTrainStochastics.build_transition_tensortrain — Method
build_transition_tensortrain(model::ChainModel; update_rule, bond=5, Q=2, σ=x -> 2x - 3, p0=0.0) -> TensorTrain

Transition operator of one step of the chosen dynamics.

For a ChainModel, update_rule is one of

  • :sequential: Glauber, one random site per step (sequential builder);
  • :metropolis: Metropolis, one random site per step;

  • bond::Int: maximum bond dimension for the compressions (graph: bond = 0 means no compression).

  • p0::Real: inertia of the parallel Glauber rule (chain only).

Example

TensorTrainStochastics.inverse_secant_tt — Method
inverse_secant_tt(B, bond; tol=1e-12, maxsteps=100, steps=nothing, verbose=false)

Pointwise inverse X(x) ≈ 1 / B(x) by the secant-type iteration X_{k+1} = X_k + X_{k-1} (I - B X_k) (Hadamard products), whose residual satisfies e_{k+1} = e_k e_{k-1}. Keywords

  • tol::Real, maxsteps::Int, steps: see inverse_tt.
  • verbose::Bool: show a progress bar and print ‖I - B X‖ every 5 steps.

Example

X = inverse_secant_tt(B, 10)
source
TensorTrainStochastics.inverse_tt — Method
inverse_tt(B, bond; tol=1e-12, maxsteps=100, steps=nothing, verbose=false)

Pointwise inverse X(x) ≈ 1 / B(x) by the Newton–Schulz iteration X_{n+1} = X_n (2 - B X_n) (products are Hadamard products), compressing to bond dimension bond after every product. Starts from X_0 = c (2 - c B) with c = 1 / (2 · estimate of max|B|), which converges for B > 0.

By default the iteration stops when the relative L2 residual ‖1 - B·X‖₂ / ‖1‖₂ drops below tol. The residual is computed exactly from the tensor trains, against a left-orthogonalized copy of B (so it does not depend on the gauge of B) and by orthogonalization rather than dot (which cannot resolve residuals below about 1e-8); a warning is emitted if that does not happen within maxsteps iterations. Newton–Schulz needs about log₂(max B / min B) iterations before it converges quadratically, so wide dynamic ranges need more steps. Bond truncation sets a floor on the reachable residual.

B is rescaled in place by normalize_eachmatrix! (its value is unchanged).

Keywords

  • tol::Real: target relative L2 residual.
  • maxsteps::Int: maximum number of iterations.
  • steps: if an Int, run exactly that many iterations with no convergence check (the behaviour before the tolerance was introduced).
  • verbose::Bool: print the starting constant, a progress bar and per-step diagnostics.

Example

X = inverse_tt(B, 10)                 # until ‖1 - B·X‖₂/‖1‖₂ < 1e-12
X = inverse_tt(B, 10; steps = 20)     # exactly 20 iterations
source

TensorTrainStochastics.tt_swap — Method
tt_swap(m1::ChainModel, m2::ChainModel, n, bond; tol=1e-12, maxsteps=100, steps=nothing, verbose=false) -> TensorTrain

Smooth tensor-train approximation of the Metropolis swap acceptance min(1, r):

a(x, y) = (r + r² + … + rⁿ) / (1 + r + … + rⁿ) ,   r = exp((β₁ - β₂)(E(x) - E(y))) ,

which tends to min(1, r) as n → ∞ and satisfies detailed balance for every n. The denominator 1 + r + … + rⁿ is inverted with inverse_tt; bond bounds all compressions.

Accuracy. By default the inversion iterates until the relative L2 residual is below tol. Newton–Schulz needs roughly log₂(max/min) iterations before converging, so when r (hence 1 + r + … + rⁿ) spans many orders of magnitude (large |β₁ - β₂| · ΔE or large n) it takes more steps, and inverse_tt warns if maxsteps is not enough. A fixed steps skips the convergence check: with steps = 10 the result degrades once the range exceeds about 3 orders of magnitude.

Keywords

  • tol, maxsteps, steps, verbose: passed to inverse_tt.

Example

m1 = ChainModel(ones(3), zeros(4), 0.5)
a = tt_swap(m1, with_beta(m1, 0.8), 3, 10)
source
