TensorTrainStochastics.AbstractSpinModel — Type
AbstractSpinModel

Supertype of the Ising-type spin models. Every subtype carries its couplings, its local fields and an inverse temperature β, and implements nsites, local_fields and with_beta.

source
TensorTrainStochastics.ChainModel — Type
ChainModel(J, h, β)

Open one-dimensional Ising chain with energy

E(σ) = -Σᵢ J[i] σᵢ σᵢ₊₁ - Σᵢ h[i] σᵢ ,   σᵢ ∈ {-1, +1}.

Arguments

  • J::AbstractVector{<:Real}: nearest-neighbour couplings, J[i] couples sites i and i+1 (length N-1).
  • h::AbstractVector{<:Real}: local fields (length N).
  • β::Real: inverse temperature. Any real number except NaN is accepted; negative values are needed internally (e.g. the replica swap ratio uses β₂ - β₁).

The vectors are copied, so later changes to the inputs do not affect the model. Throws an ArgumentError if N < 2, length(J) != N - 1 or β is NaN.

Example

m = ChainModel(ones(4), zeros(5), 1.0)   # homogeneous chain, N = 5
nsites(m)                                # 5

TensorTrainStochastics.GraphModel — Type
GraphModel(A, β)
GraphModel(m::ChainModel)

Ising model on an arbitrary graph, encoded in a symmetric matrix A: A[i,j] = J_ij for i ≠ j (0 means no edge) and A[i,i] = h_i. The energy is

E(σ) = -Σ_{i<j} A[i,j] σᵢ σⱼ - Σᵢ A[i,i] σᵢ .

Arguments

  • A::AbstractMatrix{<:Real}: square, symmetric, at least 2×2.
  • β::Real: inverse temperature (any real except NaN).

The matrix is copied. Throws an ArgumentError if A is not square, smaller than 2×2, not symmetric, or if β is NaN.

GraphModel(m::ChainModel) builds the equivalent tridiagonal model (same β).

Example

g = GraphModel([0.1 1.0; 1.0 -0.2], 0.5)   # two coupled spins
GraphModel(ChainModel([1.0, 2.0], zeros(3), 1.0)).A

TensorTrainStochastics.compose_transitions — Method
compose_transitions(A, B)

Composition of two transition operators in tensor-train form (4-index cores [left, right, σ, σ_next]): first A, then B,

C(σ, σ'') = Σ_σ' A(σ, σ') B(σ', σ'') .

As matrices over configurations this is the product W_A * W_B.

Example

A2 = compose_transitions(A, A)   # two steps

TensorTrainStochastics.hadamard — Method
hadamard(A, B)

Pointwise (Hadamard) product of two tensor trains of the same type with matching physical dimensions: hadamard(A, B)(x) = A(x) * B(x). Bond dimensions multiply.

Example

C = hadamard(A, B)
evaluate(C, x) ≈ evaluate(A, x) * evaluate(B, x)

TensorTrainStochastics.inverse_secant_tt — Method
inverse_secant_tt(B, bond; steps=20, verbose=false)

Pointwise inverse X(x) ≈ 1 / B(x) by the secant-type iteration X_{k+1} = X_k + X_{k-1} (I - B X_k) (Hadamard products), whose residual satisfies e_{k+1} = e_k e_{k-1}. Compresses to bond dimension bond after every operation.

B is rescaled in place by normalize_eachmatrix! (its value is unchanged).

Keywords

  • steps::Int: number of iterations.
  • verbose::Bool: show a progress bar and print ‖I - B X‖ every 5 steps.

Example

X = inverse_secant_tt(B, 10)
source
TensorTrainStochastics.inverse_tt — Method
inverse_tt(B, bond; steps=10, verbose=false)

Pointwise inverse X(x) ≈ 1 / B(x) by the Newton–Schulz iteration X_{n+1} = X_n (2 - B X_n) (products are Hadamard products), compressing to bond dimension bond after every product. Starts from X_0 = c (2 - c B) with c = 1 / (2 · estimate of max|B|), which converges for B > 0.

B is rescaled in place by normalize_eachmatrix! (its value is unchanged).

Keywords

  • steps::Int: number of Newton iterations.
  • verbose::Bool: print the starting constant, a progress bar and per-step diagnostics.

Example

X = inverse_tt(B, 10; steps = 20)

TensorTrainStochastics.random_chain_model — Function
random_chain_model(N, a=-1.0, b=1.0; rng=Random.default_rng(), β=rand(rng)) -> ChainModel

Random open chain of N sites with couplings J and fields h drawn uniformly from [a, b). Draw order: β (if not given), then J, then h.

Arguments

  • N::Integer: number of sites (N ≥ 2).
  • a::Real, b::Real: bounds of the uniform distribution for J and h.

Keywords

  • rng::AbstractRNG: random number generator.
  • β::Real: inverse temperature (default: uniform in [0, 1)).

Example

using Random
m = random_chain_model(6; rng = MersenneTwister(1), β = 2.0)

TensorTrainStochastics.replica_product — Method
replica_product(A, B)

Joint tensor train of two independent replicas: C((x, y)) = A(x) * B(y).

  • 3-index cores (distributions): physical index of C is the combined index x + Q*(y - 1) (size Q²), i.e. for Q = 2: 1 = (1,1), 2 = (2,1), 3 = (1,2), 4 = (2,2). The swap x ↔ y is the permutation [1, 3, 2, 4].
  • 4-index cores (transition operators): C((x,y), (x',y')) = A(x, x') * B(y, y'), with the same combined-index convention on both physical indices.

Example

P = replica_product(boltzmann_1, boltzmann_2)   # π₁ ⊗ π₂ on the joint state
